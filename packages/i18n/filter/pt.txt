# Chat filter: Portuguese in general. One word or phrase per line; "#" starts a comment.
#
# Words are compared in their plain form (packages/i18n/src/filter.ts): lower
# case, no accents, digits and symbols read as the letters they imitate,
# repeated letters collapsed. Write each word once, as it is normally spelled.
# A word is only found whole, never inside another word.

# the moderators review it in Task 3.6 and with the first reports from real
# players. What the game does with a match (hide the word, hold the message,
